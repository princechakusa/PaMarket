What Exactly Changes

Pattern-by-Pattern Diagnosis & Fix

Header / Hero
Now: Full-width gradient blue block (linear-gradient(#1A3A8F → #2952c8)) — the single strongest AI-template signal. Action buttons jammed inside the colored hero area.
New: White surface with avatar at 72px rounded-square, name in Inter 700 dark, metadata in muted neutral-400. Color lives only in small badges. Action row is its own strip below.
Section Headers
Now: Blue-tinted headers with icon + text-transform:uppercase;letter-spacing:.5px;color:#1A3A8F on every section — classic form-builder pattern.
New: Clean Inter 600 13px / 14px, color:#0F172A, sentence case, no decorative icons. Hierarchy via spacing and weight, not color.
Skill Chips / Tags
Now: background:#1A3A8F14;border:1px solid #1A3A8F30;color:#1A3A8F — blue-tinted bordered pills. Heavy-handed and Template™.
New: background:#F1F5F9;color:#475569;border:none;border-radius:999px — neutral quiet chips. Accent only for availability/open-to-work status.
Buttons
Now: 4 competing CTAs in the bottom bar all same height. Multiple gradients (green for save, blue gradient for edit). Heavy box shadows on primary buttons.
New: One primary CTA (#0F172A flat fill, 600 weight). Secondary as ghost border. Tertiary as icon-only. No gradients on any button.
Topbar / Navigation
Now: Solid #1A3A8F blue bar with white text and ghost-circle back button. Matches government-portal aesthetics.
New: White surface, 1px neutral-100 border-bottom. Back button as 32px neutral-100 rounded square. Title in Inter 600 dark. Contextual action text-link on right.
Form Labels
Now: text-transform:uppercase;letter-spacing:.5px;font-weight:700;font-size:12px — 100% Bootstrap form-builder look.
New: Sentence case, font-size:13px;font-weight:500;color:#475569. Inputs with border:1px solid #E2E8F0;border-radius:8px. Focus ring: 3px #2563EB18.
Card Stacking
Now: Every section wrapped in its own white card with border + shadow. Sections float on a grey bg. Creates a "dashboard widget" feel.
New: Full-bleed white sections separated by 8px neutral-50 gaps (iOS Settings pattern). Sections breathe as content areas, not floating cards.
Info Banners
Now: Tinted-background inline banners (#22c55e18, #1A3A8F18) with colored text and icon. Feels like a Bootstrap alert.
New: Removed. Context delivered through section subtitles in neutral-400. Critical info as a left-border callout if absolutely needed.
Scope of changes: The CSS system (styles.css + pages-patch.css) gets updated tokens. The HTML generation in jobs.js (ViewCandidateCV, CandidateProfile) and profile.js (JobSeekerProfile) gets new markup patterns. The topbar helper in app.js (innerTopbar) gets the new white-surface treatment. No functionality changes — pure visual layer.
